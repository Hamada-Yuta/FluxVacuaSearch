# Reference run

These numerical summaries, software versions, model settings and sample split
indices were generated by the bundled analysis commands on the distributed
1,296,633-row sample using Python 3.11.3. They provide reference values for a
rerun. No individual predictions or fitted model weights are required here.

NPZ arrays are read with `numpy.load`. See the main README and the array-writing
code in each analysis entry point for the row-identity conventions. In particular,
conditional-regression files contain both stable-sort positions and source rows.

The bundled scripts were rerun against the complete adopted sample. The
classification and forward-regression metrics and split arrays match the
existing numerical run. All 26 conditional-regression R-squared scores match;
RMSE and MAE differ only at floating-point rounding level. The Chapter 4
correlation matrices match, and direct instanton evaluation agrees with the
previous values to floating-point precision. These comparisons concern the
numerical analyses, rather than a fresh scan or independent physical validation.
